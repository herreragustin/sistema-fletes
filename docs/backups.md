# Backups de base de datos

Antes de limpiar los datos demo del sistema se genero un backup local de la base SQLite.

## Backup generado

- `backups/db_antes_limpieza_demo_20260611_2023.sqlite3`

## Convencion usada

- Carpeta: `backups/`
- Archivo: `db_antes_limpieza_demo_YYYYMMDD_HHMM.sqlite3`

## Importante

- Los backups locales no se suben a GitHub.
- La carpeta `backups/` queda ignorada por Git.
- El objetivo del backup es poder volver al estado previo si hiciera falta revisar o recuperar informacion.
